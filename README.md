If you are buying a device specifically for PsNee, I would strongly recommend using the [latest official PsNee](https://github.com/kalymos/PsNee) on supported hardware, partially because the officially supported boards can have a much lower power consumption, partially because this fork is not based on the very latest PsNee code, and ultimately because this port has not undergone a significant amount of testing like the original project has.

With the RP2040, the power consumption is definitely higher than any of the officially supported PsNee hardware, so it should be taken into account. I don't think it's high enough that it's very concerning, but it's higher than the traditional modchips. While I don't personally that it's too much current to pull from the mainboard (after all the Parallel port was expected to power devices which consumed much more than the RP2040 itself does), it's something to keep in mind.

If the board has both VSYS and 3.3v, prefer using VSYS for the power input.
